# result

Заполненные таблицы Главы 2 экономического анализа ООО «РЕГИОНСПЕЦКОМ» и сопроводительные документы.

Источник данных — `palermo4qd/diplomatic-` (бухгалтерская отчётность 2023–2025 гг. и оборотно-сальдовые ведомости).

## Состав

- `ГЛАВА 2 (заполненный).docx` — шаблон с заполненными исходными данными.
- `Замечания.md` — расхождения, единицы измерения, отсутствующие данные.
- `Отчёт_по_заполнению.md` — таблица-отчёт по каждой заполненной ячейке (что искал, где нашёл, значение).
- `fill_template.py` — скрипт переноса данных (для воспроизводимости).
